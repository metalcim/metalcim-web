# metalcim-web

Sitio de **MetalCim** — https://metalcim.com.mx

- `site/` — todo lo que se publica en el sitio.
- `AGENTS.md` — reglas para editar el sitio (léelas antes de cualquier cambio).
- `.github/workflows/deploy.yml` — publicación automática al hosting.

## Cómo se hace un cambio

1. Edita los archivos de `site/` en una rama nueva o pide el cambio a Codex.
2. Abre un **pull request** hacia `main`.
3. Antonio lo revisa y lo aprueba.
4. Al aprobarlo, GitHub publica los archivos en el hosting en menos de un minuto. El avance se ve en la pestaña **Actions**.

Para revisar el sitio localmente, abre `site/index.html` en el navegador.
